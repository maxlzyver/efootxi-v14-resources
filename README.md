# efootxi 1.4 resources / 加密资源

This repository distributes encrypted runtime resource packs and their manifests for efootxi 1.4.
本仓库仅用于 efootxi 1.4 加密运行资源和配套清单。

Download the APK and read player announcements at [maxlzyver/efootxi](https://github.com/maxlzyver/efootxi).
安装包下载及玩家公告继续使用上方原仓库地址。

Encrypted resource preparation is in progress. Version 1.3.2's resource channel will not reference this repository. Install 1.4 before using new resources.
加密资源正在准备；1.3.2 的资源频道不会接入这里，请先安装 1.4。

No application source code, APK, player saves, private keys or internal build reports are published here.
这里不发布应用源码、APK、玩家存档、私钥或内部构建报告。
